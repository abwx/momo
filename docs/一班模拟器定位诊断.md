## 1. 网上对照：真实节目生态

公开信息（2026 年 6–7 月，B 站 TF 家族 / 媒体报道口径）：

| 项 | 内容 |
|----|------|
| 节目 | 《突围Ⅱ·破局》（暑期集训纪录片 / 考核企划） |
| 人 | 四代 15 人（与仓库 `characters.ts` 名单一致） |

| 考核形态 | 声乐 / 舞蹈 / 团体对抗、**24 小时单曲互换**、多轮舞台 |

**练习室压力 → 舞台考核 → 排名公开 → 分班升降 → 粉丝投票托举 → 谁被看见 / 谁掉队。**

## 2. 当前仓库实际做成了什么

### 2.1 对外定位（文案）

- 入口：`VcHomeView.vue` ——「**团综制作人模拟器** / 一班模拟器」
- 角色幻想：**你是制作人**，决定谁有镜头、谁被虐粉、谁能逆袭
- 不是练习生本人，也不是纯打投粉丝

### 2.2 可玩主循环（真正在跑的）

```text
入口 → 大厅 → 排班(本命/热度)
  → 录制台（选题 / 机位 / KPI / 控评 / 开嗑 / 复盘）
  → 每节：卡机位 + 选题结算
  → 季终综合评级 SSS–F
```

- 节目单：`groupShowProgram.ts` —— 四期：分组考核 / 清晨任务 / 双人舞台 / 舞台释出  
- 事件：`groupShowEvents.ts` —— 叫早、宿舍夜谈、互选搭档、选曲排序、释出舞台……  
- 开场仍可能拼上旧池里的 `openingEvent`（Center 席位之争）——气质更偏选秀，和后面「团综录制」略跳戏（`SCreateProgramSeasonEvents`）

### 2.3 没有的（但对「突围」很关键）

- **无一班 / 二班**
- **无淘汰 / 降班 / 末位危险区**
- **无考核打分驱动命运**（RANKING 只调人气，不决定去留）
- **无出道位 / 破局席位结算**
- **无高会投票 / 打投玩法**（有控评粉盘，但是制作人砸经费，不是粉丝托举）
- 成员基本只有 **人气单轴**，没有「考核分 / 舞台完成度 / 班籍」分轨

### 2.4 资源语义（为什么玩起来像「公司后台」）

- 经费、镜头份、成片权、热搜位  
- 控评改粉盘、开嗑抬嗑点  
→ 这是 **剪辑室 + 公关室** 的资源，不是 **练习室 + 排名榜** 的资源。

### 2.5 内容库分裂

| 库 | 气质 | 是否进主赛季 |
|----|------|--------------|
| `groupShowEvents` + `groupShowProgram` | 团综录制 / 剪辑抉择 | **是，当前主线** |
| `events.ts` eventPool | 大量选秀 / Center / 消音 / 出道夜 | 注册在 map，**不主导当前节目单** |
| `additionalEvents` | 品牌正片、剪辑室花絮等 | 偏制作人 |

所以你会感觉：**人是四代，壳是突围，肉是团综制作人。**

## 3. 错位对照表（真实突围 vs 当前游戏）

| 维度 | 真实《突围Ⅱ·破局》 | 当前游戏 | 玩家感受 |
|------|-------------------|----------|----------|
| 你是谁 | 旁观 / 打投托举 / 心疼本命 | **制作人剪片子** | 「我怎么在公司上班」 |
| 紧张从哪来 | 排名、分班、掉队 | 预算不够、成片加成 | 紧张感不对味 |
| 每回合在干什么 | 看考核、投票、争资源 | 选题 + 卡机位 + 控评开嗑 | 像后台工具，不像突围 |
| 双人舞台 | 投票定组、影响破局资源 | 互选 / 开嗑营业 | 有形无「生死感」 |
| 胜利条件 | 进一班 / 被看见 / 破局 | 制作人评级 SSS–F | 胜利叙事错位 |
| 引流钩子 | 「帮本命突围」强代入 | 「学会怎么剪团综」弱代入 | 粉圈传播力偏弱 |

**一句话**：不是数值坏了，是 **产品幻想（Fantasy）选错了轨**；在错误幻想上把粉圈话术、机位、KPI 打磨得再好，也会越做越像「奇怪的团综后台」。

## 4. 若本意是「一班模拟器引流」，建议的产品北极星

### 目标（建议）

做一个 **轻量、可分享、强本命代入** 的：

> **「带本命打突围」模拟器**  
> 几分钟一局，核心情绪是：排名焦虑 / 托举成功 / 险些掉班 / 舞台高光。

### 非目标（建议先砍）

- 完整影视工业制作人模拟  
- 真实经费账本、剪辑权管理系统  
- 长线养成 RPG（除非二期再加）

### 最小可通关幻想（MVP 建议）

1. 选本命  
2. 多轮考核（声乐 / 舞 / 双人 / 团体）  
3. 公开排名 + **一班席位压力**  
4. 有限次「托举 / 资源倾斜 / 加练」选择（可保留制作人身份，但目标必须是突围）  
5. 结算：本命是否破局进一班 + 分享文案  

制作人身份可以保留为壳，但 **胜负必须绑在分班 / 排名上**，不能只绑制作人评级。

## 5. 三条改造路线（先选型，再写方案）

| 路线 | 做法 | 引流强度 | 改动量 | 风险 |
|------|------|----------|--------|------|
| A. 硬转向突围 | 主循环改成考核→排名→分班；团综制作降级为调味 | 高 | 大 | 现有机位/控评/开嗑要重挂 |
| B. 双幻想分层 | 外层「突围季」，内层偶尔进剪辑室事件 | 中高 | 中 | 两套系统仍可能打架 |
| C. 维持制作人，只换皮 | 文案改突围，逻辑仍剪辑室 | 低 | 小 | **治标不治本**，继续怪 |

**建议：选 A 或 B，不要选 C。**
